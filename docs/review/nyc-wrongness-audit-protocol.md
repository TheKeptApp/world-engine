## 2. Wrongness taxonomy

Follow archetypes §§1–2/5–6: form, use and site are separate; mapped parts/dimensions outrank generic fallback; `layer` is order, not metres; unknown never earns an invented house or landmark. Stage 0b remains blocked by the existing look gate. Classifier implementation status is not visual truth. These are proposed audit flag definitions, not permission to repair code or a new look-gate threshold.

| Code | Confirmed error and counting unit | Exclusions / unknown handling |
|---|---|---|
| MB — missing building | One expected physical building assembly is absent where it should be visible. Count once per stable assembly ID, even if several parts are absent. If only a part is missing, use WS. | Independent reference must establish existence at the inventory date and expected visibility. Truly occluded/offscreen structures are not visual omissions. A source acquisition omission can be confirmed against independent evidence; record pipeline stage. No independent census means completeness unknown. |
| WH — wrong height | One visible assembly has a supported height/setback-height mismatch, using the same ground datum and roof/spire convention. Flag when discrepancy exceeds **max(3 m, 10% of reference height)** and combined stated uncertainty. Record signed metres and relative error. | Threshold is an authored triage rule, not surveyed accuracy or an approved acceptance tolerance. An inferred height is not automatically wrong; an unsupported reference is unresolved. Do not infer height from perspective alone. Spires/antennas are separate labelled components. |
| WS — wrong shape | One assembly has wrong footprint, topology, roof family, podium/setback/part composition or duplicated/intersecting mass, supported by matched evidence. Count at most once per assembly; list subfaults. | Ignore missing photographic detail or pack-specific wall hue. Do not also count a pure vertical-scale error as shape unless another independent form error exists. Partial missing parts belong here rather than MB. |
| WL — wrong layering | One distinct crossing/stack relation is wrong: bridge/elevated deck at grade, incorrect over/under order, tunnel drawn as surface road, broken approach continuity, duplicate deck or parent/part overlap. Key by participating stable IDs and crossing location. | Count relation once, not every segment/triangle/camera pixel. Never convert `layer=1` to a guessed height. A suppressed underground interior is expected, not MB. Unsupported deck elevations or an unverifiable crossing are unresolved; known wrong omission is recorded with evidence. |
| WV — wrong vintage | One assembly or infrastructure entity demonstrably represents the wrong physical state at the inventory date: construction/demolition/rebuild absent, or wrong era-specific mass/roof treatment contradicted by dated evidence. Record `snapshot-stale` versus `form-era`. | Source age alone does not prove error. Building age/use/name alone does not prove architectural shape; no guessed style from names. Unknown acquisition date or conflicting chronology is unresolved. Seasonal colour is not building vintage. |

False-positive extra buildings receive an `EXTRA` companion count with a generated ID and dated reference; retain this separately so a false building cannot disappear from the audit simply because it is absent from the expected list. No logo, brand, personal-location or residential-identity collection is needed.

## 3. Counting and blinding

1. **Freeze the denominator first.** Before candidate images, save a hash/versioned reference inventory and viewpoint-visible subset per cell, plus independent evidence/source dates and confidence. Use physical assemblies, not raw OSM ways, relations, tiles or `building:part` members. Assign by validated assembly footprint centroid; count a crossing by its intersection point. Record boundary-spanning assemblies and retain whole geometry. Cells overlap intentionally (NYC-04 is inside NYC-01); report each independently and deduplicate IDs for any all-NYC total.
2. Record four pipeline counts from archetypes §4: acquired, classifiable, geometry-sufficient and generated/exported. For each taxonomy separately record `eligible`, `assessed`, `confirmed errors`, `unresolved` and `not visible/not applicable`. WH needs a credible height, WV dated evidence and WL crossing relations: **their denominators differ**. Report `errors/assessed` plus `assessed/eligible` coverage, not errors divided by every loaded object. If no independent inventory exists, the eligible total is unknown; report raw findings without a completeness percentage.
3. **Sloan's blind method:** a preparer copies original captures unchanged, shuffles neutral labels with recorded randomness and holds the build/candidate key separately. A3 sees fixed reference evidence and the anonymous renders, but no commit, variant, expected winner or previous score. Lock per-ID errors, uncertainties, six §M aspects/overall where applicable and reasons with a timestamp before unblinding. For a baseline-only audit conceal build identity; say plainly that this is not a blinded before/after trial. Familiar landmarks/camera scale cannot be made truly blind. Source/reference identity may be visible to match objects; candidate identity stays hidden.
4. Run one inventory pass per cell in stable spatial order, with no selecting only the worst or easiest examples. Save evidence coordinates/crops privately when needed. MB suppresses WH/WS scoring for that absent object; those become not assessable. WV may coexist with MB or WS only when an independent dated fact supports it. Report both summed taxonomy flags and the **union of unique erroneous entities**, so multi-category faults are not advertised as several missing buildings. WL relations have a separate union from building entities.
5. After locked findings, reveal labels and reconcile source IDs/measurement uncertainty without changing a grade to match expectations. Record any factual correction with its original finding and reason. Same-frame repeats check grader variance under §N; reference uncertainty and renderer defects remain separate. A second review of disputed cases uses the same fixed evidence. No capture/score currently exists, so every result starts `not run` rather than zero.
6. Report per cell: `reference/build/renderer | eligible+assessed counts by class | MB WH WS WL WV EXTRA | unresolved | unique building errors | crossing errors | six aspects/overall | budget evidence | limitations`. Preserve general hold-out rules: no block-specific tuning; Sloan gains paired with hold-out losses are reject-flagged. Wrongness counts are structural evidence, not a replacement for the existing visual gate. Height/massing review can additionally use the [metro skyline check](../screenshots/metro-reference/README.md#metro-skyline-check), with supported tallest-ten ranks and unknowns disclosed.
