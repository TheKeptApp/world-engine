Must be exact before building

  • Mapped shoreline, harbor entrances, breakwaters and dock layout
  • Drive carriageways, ramps, crossings, trail paths and relative elevations
  • Beaches versus hard revetments from actual shoreline data
  • Camera lakeward heading and visible tower positions; no opposite coast inserted

Can simplify

  • Sand as a smooth solid; no grains or footprints
  • Harbor vessels as optional unbranded hull blocks only when mapped/live
  • Clean tree instances; broad park color masses
  • Flat-band water and soft shore color transition, no dense waves
