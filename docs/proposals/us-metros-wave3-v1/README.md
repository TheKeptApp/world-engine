# US metros wave 3 · Style B

Open index.html in Safari; use Phone view for a 390 CSS-pixel layout. All deliverables stay in this folder. No git or engine changes.

## Scope

12 metro boards, 48 archetype sheets, 24 district boards and 12 block before/paint-over comparisons. PNG artwork carries the reference scene; HTML carries exact authored labels, metres, swatches and screen-size tiers. metro-values.json is the values sheet; prompts.json logs every generation/edit; image-manifest.json identifies final artwork.

## Style

Approved Bible calibration + house archetypes + wave2 + Japan/infrastructure references: real proportions, rich simplified matte surfaces, soft mid-afternoon light. No people, dogs, brands, badges, real murals or readable signage. Shared lighting/surface blocks copied from wave2; inherited old approval provenance ambiguity is not a new approval request—the user named the current Bible as approved. Sun/weather in production override the clear review fixture. Exposure applies once.

## Evidence boundaries

Catalog coverage is incomplete for this wave: St Louis, Kansas City, New Orleans, Portland and Salt Lake City lacked metro rows in the supplied inputs. New official-source excerpts support selected local families; the rest are expressly authored plausible proposals requiring district survey. All dimensions, pitches, hexes, planting choices, ground-cover choices and district arrangements are proposals, not measurements or abundance claims. Sources are linked on metro boards and in sources.md. Tree lists are candidate/historical/contextual evidence, never current metro-wide shares. Minneapolis sources do not establish all St Paul details.

No Canadian/US engine frames were supplied for these metros. Before images are newly generated plain concepts; paint-overs preserve their camera and block arrangement as edit invariants, with possible local image drift. Neither image certifies real surveyed geography. Triptychs are illustrative cameras, not registered 3D projections.

## Phone implementation

Building projected height: <6 drawable pixels retains silhouette; 6–20 primary structure; >20 selective detail, with individual feature cutoff2px. Keep roof/porch topology, foundations, terrain contact and party walls; omit individual brick joints, siding lines, tile ridges and leaf geometry. Use lobe canopy geometry and shared material families. Existing v2 scene buckets retain the 60fps /10ms total GPU target. No added global pass/shadow map/day light. Real camera/LOD/performance still need engine/device verification.

## Distinctness

Twin Cities boulevard/porch rhythm; Detroit brick side-gables; St Louis tight brick/parapet/stoop rhythm; Kansas City stone-base hillside porches; New Orleans long narrow raised cottages; Las Vegas xeric walls/stucco; San Diego coastal mesa tile/courtyard; Portland wooded wood-porch slopes; Salt Lake brick/grid/Wasatch; Charlotte Piedmont oak/brick; Tampa coastal live-oak/bungalow; Orlando inland lake/subdivision roofscape. These are district composition choices, not citywide stereotypes.
