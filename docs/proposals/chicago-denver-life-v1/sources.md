# Source scope

Numerical dimensions, speeds, counts and multipliers are authored fallback targets. No crowd census, vendor inventory, pole map or local footfall calibration was obtained. The user brief defines the requested cultural subjects; imagery does not establish actual location or operation.

- [CTA system map](https://www.transitchicago.com/maps/system/): Mapped transit context; not measured crowds or pictured geometry. Checked 7 October 2026.
- [RTD schedules](https://app.rtd-denver.com/schedules): Current service lookup must govern actual rail activity; no service inferred from artwork. Checked 7 October 2026.
- [CTA Wilson station project](https://www.transitchicago.com/wilson): Elevated station/platform context; not proof the composite is a specific station. Checked 7 October 2026.
- [Chicago heat booklet](https://webapps1.chicago.gov/ChicagoAlertWeb/resources/pdf/Heatbooklet.pdf): Opened hydrant is not a default heat-response automation; illustration only. Checked 7 October 2026.

Track-level geometry, collection schedules, vendor permits, rooftop features, game times and local poles require independent mapped evidence before engine placement. No repo files written.
