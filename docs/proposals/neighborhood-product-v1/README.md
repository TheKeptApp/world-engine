# Neighborhood Product v1

Internal concept and UX study • WorldEngine priority 3, after Builder • 7 October 2026

**Recommendation: prototype Common Ground, a cooperative weekly walking game, first. Use Gather as the second concept and a narrow Builder extension.** Start with adults in one curated neighbourhood. The useful social object is a shared challenge or a public event plan, never a person’s position. Neither concept depends on AR.

Open `index.html` for the concept board and ten phone screens. `concepts.md` covers five concepts; `competitive-scan.md` contains cited evidence and explicit interpretations; `prototype-90-days.md` defines scope and decisions; `privacy-and-ux.md` defines the data contract. `screens/01.html` through `10.html` are functional local UI mockups. PNG exports and mobile checks are in `phone-check/`.

## What is real here

World backgrounds are unchanged copies from style-b-calibration-v2. Its sharedLook is copied into `values.json`. UI, weather, activity totals, dates, route labels and event proposals are fictional examples. People depicted in the reference art are anonymous decorative figures, not users, presence or tracked map data. The Gather placement diagram is schematic and not measured against the photograph-like perspective. The backgrounds do not prove a live engine, routing, weather integration or actual event permission. These are working screen transitions and local toggles, not a connected app. No external publishing, invitations, analytics, host-app content or git operations.

## Product boundary

Home location remains on device, excluded from backups and telemetry. No background location, individual tracking, location-derived attendance, resident map, address-linked identity, public activity trail or people heatmap. Optional challenge contributions are anonymous aggregate inputs, delayed and withheld below a privacy threshold. Prototype testing initially uses synthetic totals; the proposed aggregation architecture must pass an adversarial privacy review before any real contributions are collected.

## Limits

The competitive scan is a desk review of the linked sources accessed on 7 October 2026, not a usability study or an exhaustive market survey. Revenue, willingness to pay, retention and privacy parameters are hypotheses. Phone checks measure layout at 320, 390 and 430 CSS pixels and exercise navigation; they are not physical-device, assistive-technology or engine performance certification. No existing WorldEngine project files were written.
