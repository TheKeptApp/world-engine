## Engine / mock policy and release gate

All E world geometry, true scale, time/shadows, rain/wetness, night lighting, moving Chicago train, Wrigley shell, creator route and village transforms, complete Miami zoom/return, globe, clouds, atmosphere, terminator and city-light appearance require real engine footage before release. There is no engine footage in this package and no current capability or performance is verified.

O allows typography, labels, cursor highlights and orbital annotation. Satellite overlay must use the same anchored coordinates and recorded element epoch/computation time; its marker is schematic. M permits concept editor chrome only with a readable “Concept interface” label; actual placement and persistence must work in engine. AI paint-overs cannot substitute for an E scene.

Capture every required action and maintain shot IDs, raw footage, locations, render settings and source timestamps in a release manifest. Validate mapped footprints/heights/curbs, Wrigley sightline, course-to-street alignment, village grounding and persistence. Run take Z end-to-end at each cut's duration; same world/anchor/sun/time, no internal edit, dissolve, texture swap, loading gap or LOD pop. See zoom-sequence.md. The former match-cut fallback is superseded: if continuity fails, fix the engine before releasing this story.

Label time-lapse, rain and night as controlled states; label transit LIVE only with source-specific fresh observations and visible source/time. If stale use labeled replay and revise narration. Satellite positions are computed from dated orbital elements, not directly observed. Night city glows use historical NASA Black Marble as distribution inspiration, not a current live night feed. See https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/ . Production should carry actual selected dataset provenance/date and required plain-text attribution.

No dogs, people, characters, logos, team names, ads or public artworks in capture. Historical superseded assets may retain older content and are excluded from the active board. Check active artwork at full and phone size. Select a brand line before recording the close. Clear music/sound rights. Verify captions, scale-level readability and exact 90 / 30 / 15s runtime at 24 fps. No commercial SDK, licensing-readiness, event approval, device FPS or survey-accuracy claim is made.
