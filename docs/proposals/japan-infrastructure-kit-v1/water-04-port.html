Form and proposal notes

Generic working port with larger quay/apron and plain warehouse/service yard adjoining a SMALL FISHING HARBOUR sheltered by modest breakwaters. A few ORIGINAL GENERIC8m fishing boats with credible long hulls, modest wheelhouses, simple rig poles, no toy hull, no emblems/registration numbers, no operators. Near looks over fishing basin edge, aerial exposes both workingport and fishingbasin, far same coastline. Docks connect, entrance remains clear, sea level coherent. No cargo brands/murals.

All new values are proposals, not surveyed dimensions or engineering standards. Numeric JSON and authoritative geometry win over illustration. Use tiers on local modules, not an entire kilometre-scale site.
