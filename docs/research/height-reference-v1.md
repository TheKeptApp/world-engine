# Independent height reference scout — A9

Research checked 8 October 2026. Scope: Sloan's Lake and West Highland, Denver; Lakeview, Chicago. Metadata, documentation and licence research only. No raw dataset was downloaded, no property/person records were collected, and no validation results are claimed. This document is the only content change; it does not promote the ladder or change pipeline, look, area or tracker files.

## Decision

**Best Denver candidate: DRCOG stereo-photogrammetric roof heights, published by Denver as Building Outlines 2022. Best Lakeview candidate: Cook County assessor residence/storey characteristics. Both are YELLOW overall pending the specific checks below. No fully cleared, independently calibrated metre-height reference covering all three areas was established.** Chicago's historical official GitHub footprints have a GREEN licence, but YELLOW reference fitness; MIT alone does not make their heights independent or current.

An administrative storey record is independent of lidar measurement, but is not a measured roof height. Stereo roof measurement is a different sensor/method, but any shared ground model or prior height import must still be checked. A different publisher, a newer lidar flight, or a 3D extrusion of the ladder's own inputs is not independent ground truth.

Ratings apply to **internal commercial-product validation with aggregate reporting**, not unrestricted redistribution of source rows. GREEN = documented permission and fit for the stated test; YELLOW = a plausible source with a named unresolved condition; RED = unsuitable for this test or no usable release established. **Raw acquisition requires overall GREEN, not merely a GREEN licence column.** No source is promoted by this research alone.

## Fixed validation sample — proposed v1, not executed

**Target: 200 buildings in each of three areas, 600 total.** Use the same selection, matching and exclusion rules everywhere. Sampling constants below are proposed protocol choices, not claims from a design pack or measured performance.

1. Freeze A1's input footprint release, candidate ladder commit/configuration, observation epoch and three explicit area polygons before seeing reference values or residuals. Reuse the existing `sloans-lake` and `lakeview-sheil-park` manifests. West Highland requires A1's delivered area manifest and footprint hash: the [frozen camera contract](../lookloop/west-highland-holdout.md) alone does not define a sampling polygon. At inspected main `55e6aed`, camera/coverage reports are not a substitute for that delivered manifest. Do not enlarge any area merely to get more valid matches.
2. Define one physical-building unit: use the frozen footprint pipeline's documented parent/relation handling, never both a parent and its parts. Keep garages, sheds, non-residential and untagged buildings in the frame so sparse/default rungs are tested. Use the unbuffered building centroid inside the area polygon; if polygons overlap, assign the building to the lexicographically first area ID. Report missing/ambiguous parent relationships as frame limitations before selection.
3. For each unique canonical key `osm:<way|relation>:<decimal_id>`, rank lexicographically by lowercase hexadecimal **SHA-256 of UTF-8 `height-reference-v1|<area_id>|<canonical_key>`**, breaking a hash tie by canonical key. Select the first `min(200,N)` keys. Freeze the release and sample digest. Use no platform-dependent hash, manual substitutions, street/block filters, reference-availability filters or “representative” picks. If N<200, report a census of N; no replacement area.
4. Generate the sample in memory from approved inputs; do not commit a row-level sample, coordinates, parcel keys or source records. Persist only source/configuration hashes, protocol version and aggregate counts/results. The immutable releases plus rule reproduce the selection. No personal fields enter logs. Hashing is a reproducibility device, not a licence or privacy exemption.
5. Join references blind to predicted height. Prefer a verified building key. For polygon matching, group reference roof parts by documented building ID, then require a unique reciprocal best overlap and intersection-over-union ≥0.70 in the same local projected CRS. Keep failures as `unmatched/ambiguous`; never choose the match whose height agrees best. Assessor joins require exactly one compatible improvement and one principal building or a verified building-card linkage; never copy a parcel-wide count to every structure. Publish match attrition by building type in sufficiently large aggregates.
6. Keep all 200 in the coverage denominator. Missing reference, unlicensed reference, ambiguous match, incompatible epoch, unknown independence, or unsupported roof convention yields **unscorable**, not zero error and not replacement. Report scored and unscored counts separately for every area and rung. If a source only covers small residential buildings, its error result applies only to that subset; it cannot certify high-rises or all buildings.
7. Run the frozen full ladder and each available fallback rung on exactly the same sample; do not discard failures. Run an additional source-withheld variant where the reference or its derivatives appear in ladder inputs. Mark shared OSM/imported heights explicitly. West Highland and Lakeview are untouched hold-outs; tuning on their outcomes consumes the hold-out and requires a new predeclared version for subsequent evaluation.
8. Publish aggregate coverage, signed bias, MAE, RMSE and nearest-rank P90 absolute error for **compatible metric references**. For storeys, publish category agreement/confusion and signed floor differences only when categories are genuinely numeric. Keep “3 or more”, split-level and partial-attic classes categorical. Report area results separately; suppress strata with n<10. Give paired candidate-versus-baseline differences on common scored buildings, plus each version's failures. No per-building examples or maps.

About 200 is a pilot, not a precision guarantee. At n=200, a simple independent-binomial estimate of 90% success has standard error about 2.1 percentage points (roughly ±4.2 points at 95%); spatial correlation and missing-reference selection can make uncertainty larger. This calculation does not give a metre confidence interval for P90. Report scored n, spatial dependence and bootstrap/interval assumptions; do not claim citywide accuracy from these three small areas.

## Error contributed by the reference

**Define the target first.** A1's [height contract](../data/building-heights.md) distinguishes p95 roof-top AGL, p50 typical roof and an edge-band eave proxy. A highest-ridge-to-lowest-ground reference is not exactly any of those. Compare only compatible roof/ground definitions; otherwise label a convention difference and do not use the residual to award A/B/C precision grades. A1's 2020 lidar and a 2022 roofprint/current assessor record may legitimately describe different buildings. Unknown change history remains unscorable for strict accuracy; report its frequency.

| Reference | Known contribution | Unknown contribution / interpretation |
|---|---|---|
| D1 integer-foot height | If rounded to nearest foot, quantization alone is ±0.1524 m, with uniform-rounding SD 0.0880 m. Rounding is **not verified**; truncation can approach 0.3048 m and adds directional bias. | Stereo roof/ground measurement, obscured ground, temporal change, matching and ridge-versus-p95 mismatch remain unmeasured. Pixel size is not height RMSE. No defensible total numeric error budget yet. |
| C1 assessor storey categories | Reference measures administrative residence type/storeys, not metres. Current encoding must be decoded; historical top-coding and partial-attic categories show why literal code-to-floor conversion is unsafe. | Unknown misclassification/staleness; “3+” has no finite upper floor bound. For a hypothetical conversion H=s·f+r, error contains f·Δs+s·Δf+Δr plus base/ground error. At an illustrative f=3 m, one wrong floor alone means 3 m; this is sensitivity, not a validated 3 m conversion. |
| C3/C4 city story counts | Discrete counts, if collection and categories are confirmed. | Unknown provenance, stale records, missing counts and duplication. No validated metre accuracy. |
| D4/C5 approved plans/permits | Drawing dimensions can supply another measurement definition. | Design-versus-as-built changes, incomplete work and roof/grade definitions can dominate nominal drawing precision. No blanket error bound. |

For observed residual `prediction − reference`, errors from both sides and any covariance contribute. Under independent unbiased errors only, residual variance equals prediction variance plus reference variance. Shared ground/footprint/import errors violate that simplification and can make apparent agreement too good. Do not subtract guessed reference error from measured MAE/RMSE or treat every disagreement as ladder failure.

To quantify reference error later, predeclare the first 20 sample keys per area under a second salt `height-reference-v1-reference-audit` for a blinded independent check after rights clearance. Use a genuinely separate as-built/survey source or commissioned roof-and-ground measurement with stated uncertainty; repeat the same rule in all areas, with unavailable checks reported rather than replaced. Two administrative sources may share mistakes. Until this audit provides a defensible uncertainty bound, report agreement with a noisy reference, not certified ground truth. No field survey, purchase or new acquisition is authorized by this proposal.
