### Building LiveSky in a cloud session (no Mac)

`scripts/livesky-linux.sh [build|test]` does everything: starts `dockerd` if needed, pulls `swift:6.2-noble` once
(needs registry-1.docker.io), copies `Sources/LiveSky`, `Tests/LiveSkyTests` and the star catalogue into a throwaway
package under `$TMPDIR/livesky-linux`, and runs `swift build`/`swift test` in the container. Only LiveSky builds on
Linux; every other target needs Apple frameworks.
