## Combined package and counsel questions

The repository already treats world-package data as an ODbL Derivative Database. [ODbL §§4.2–4.7](https://opendatacommons.org/licenses/odbl/1-0/) require appropriate notices, share-alike for publicly used derivatives and a machine-readable derivative database or qualifying alteration/method offer; internet delivery of that offer is free. Internal organizational use is excluded from §4.4 share-alike by §4.5(c). This exception does not supply missing municipal rights. Restrictions/technical measures need the qualifying unrestricted parallel route under §4.7.

`Sources/WorldGen/Profiles/credits.json` still contains `placeholder: true` and `ODBL_OFFER_URL_PENDING`. Consequently source GREEN does not make a shipped OSM-derived map GREEN. No finished archive/store build or working version-matched offer was verified by this docs-only check.

## Boundaries for a later internal experiment

Use D1 first; N1 may be a separately labelled inferred fallback. Keep source versions, licence evidence, observation dates, units and join provenance. D1 points are absolute elevations: roof-minus-compatible-ground produces AGL, not the raw Z value. N1 documentation describes modelled average AGL metres, with `-1` meaning missing; footprint confidence is not height accuracy. D2's foot-valued height/elevation conventions remain research evidence and cannot justify loading an uncleared source. These distinctions come from the cited research and [building-height contract](../data/building-heights.md), not newly measured data.

Use the same joining/QA rules for all areas; no building-specific adjustment. This permission check proves neither Sloan's completeness nor independent reference accuracy, roof-shape recovery, or a visual pass. It does not authorize a new acquisition/build task. Only this legal document changes; credits, manifests, code, data and trackers stay untouched.
