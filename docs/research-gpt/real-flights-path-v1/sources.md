# Primary sources
Checked 2026-10-07. Verified means published content read; unresolved rights are called out separately.

- **lol-api** — [adsb.lol API](https://api.adsb.lol/docs). ODbL; production contact is requested for compatibility. Status: verified published source.
- **lol-license** — [adsb.lol licensing](https://www.adsb.lol/privacy-license/). Public aggregate ODbL; contributed feeds CC0; info@adsb.lol. Status: verified published source.
- **odbl** — [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Sections 3.1, 4.2–4.7, 2.3; commercial rights and database obligations. Status: verified published source.
- **smes** — [FAA STDDS SMES agreement v1.4](https://aa.data.faa.gov/data/service.jsf?uuid=4ad245f2-038f-47c0-be25-5e3b77ed748b). Actual surface service agreement; additional SDD section 4.5 must be obtained. Status: verified published source.
- **scds** — [SCDS access agreement v1.0](https://support.swim.faa.gov/hc/en-us/article_attachments/29623502764692). Cloud access and aircraft suppression obligations. Status: verified published source.
- **faq** — [FAA SWIM FAQ](https://www.faa.gov/air_traffic/technology/swim/questions_answers). Currently no data fee; consumer pays interface development. Status: verified published source.
- **stdds** — [FAA STDDS](https://www.faa.gov/air_traffic/technology/swim/stdds). ASDE-X/ASSC and other tower systems; not all towers have surface surveillance. Status: verified published source.
- **portal** — [SWIFT support](https://support.swim.faa.gov/hc/en-us). Current onboarding support. Status: verified published source.
- **guidelines** — [SCDS guidelines v1.1](https://www.faa.gov/sites/faa.gov/files/air_traffic/technology/swim/governance/SCDS-Guideline-Document_v1.1_09.11.2024). Internal redistribution and subscription standards. Status: verified published source.
- **ladd** — [FAA LADD](https://www.faa.gov/pilots/ladd). Aircraft blocking program. Status: verified published source.
- **pia** — [FAA ADS-B privacy](https://www.faa.gov/air_traffic/technology/equipadsb/privacy). PIA changes transmitted aircraft address; RF broadcasts remain. Status: verified published source.
- **law18** — [18 USC 2511](https://uscode.house.gov/view.xhtml?edition=prelim&num=0&req=granuleid%3AUSC-prelim-title18-section2511). Aeronautical interception exception; not standalone commercial legal opinion. Status: verified published source.
- **law47** — [47 USC 605](https://uscode.house.gov/view.xhtml?edition=prelim&num=0&req=granuleid%3AUSC-prelim-title47-section605). Radio publication/use restrictions and exceptions. Status: verified published source.
- **sdr** — [Pro Stick Plus](https://flightaware.store/products/pro-stick-plus). $45.99 listed; 1090 filter; inventory not guaranteed. Status: verified published source.
- **antenna** — [FlightAware antenna](https://flightaware.store/collections/antenna/1090). $49.99 listed. Status: verified published source.
- **pi** — [PiShop Pi4 kits](https://www.pishop.us/product-category/raspberry-pi/raspberry-pi-kits/pi-4-b-kits/). Budget kit from $116.95; variant price must be checked. Status: verified published source.
- **setup** — [ADSB.im quick start](https://adsb.im/howto). Pi Imager and browser setup; guide warns it is old. Status: verified published source.
- **ui** — [ADSB.im current interface](https://adsb.im/using). Sharing configuration; receiver location and MLAT privacy. Status: verified published source.
- **mac** — [ADSB.im VM FAQ](https://adsb.im/faq). OVA/USB passthrough option; known MLAT issues. Status: verified published source.
- **fi** — [adsb.fi data terms](https://github.com/adsbfi/opendata/blob/main/README.md). Noncommercial self-service; contact for commercial. Status: verified published source.
- **airplanes** — [Airplanes.live terms](https://airplanes.live/terms-of-use/). Retrieved page contains heading but no substantive grant; commercial rights unverified. Status: unverified commercial permission.
- **hub** — [ADSBHub disclaimer](https://www.adsbhub.org/disclaimer.php). Website download permission noncommercial; commercial feed rights not established. Status: verified published source.
