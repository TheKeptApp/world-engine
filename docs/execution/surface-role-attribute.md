Mapped **material** tags must be examined independently: roof uses supported `roof:material`, wall uses supported `building:material`; role-specific door/trim tags only if P2 defines a supported mapping with the correct scope. An explicit `roof:colour` is not evidence of terracotta. Otherwise material class is unknown, provenance none. Recognized mapping outranks an inference; unrecognized raw tags remain in existing source metadata and are reported unsupported, not guessed from hue.

## 2. Smallest conservative addition: a triangle attribute in a companion

Recommend an **optional, separately addressed companion**, `surface-roles/<area>/index.json` plus `triangles.u16le`, schema **`worldengine.surface-roles/1`**. A new consumer receives its URL explicitly; no reference is added to `world.json`, no new GLB accessor is inserted, and no files are put inside the immutable legacy package/archive. Existing consumers never discover or fetch it. This is an additive package semantic extension, not a new world dataset.

Each final indexed triangle has **one little-endian UInt16**: bits 0–2 role (`0 other, 1 roof, 2 wall, 3 trim, 4 door`; 5–7 reserved), bits 3–7 material-class ID (`0 unknown`, up to 31 other classes), bits 8–9 material provenance (`0 none, 1 mapped_tag, 2 family_inference`, 3 reserved); bits 10–15 zero. Table IDs are explicit/stable, never traversal-assigned. Candidate class table: unknown, brick, stone, wood, metal, concrete, render, glass, asphalt, clay_tile, slate, bituminous_shingle; these names are proposals, not claims that each family has an approved inference. Unsupported/reserved values fail extension validation; an old renderer may ignore the entire extension.

The index contains roles/materialClasses/provenance tables and fixed interpretation/version rules, immutable base `world.json` SHA-256, payload path, and entries binding each GLB path/SHA-256, LOD, mesh index, primitive index, triangle count and 4-byte-aligned byte offset. Primitive triangle ordinal means the original index array’s consecutive triplet ordinal. Include the existing scene-feature-table reference for provenance: `_FEATURE` resolves the source/generated record; mapped role chooses its supported tag, inferred role chooses its versioned family rule. Reject mismatching hashes/counts, mixed feature IDs on an asserted building face, missing inference witnesses or nonzero material with provenance none. Unknown/unrecorded roles use other/unknown/none; they never trigger a palette adjustment. Same-colour roof and door remain distinguishable.

Use dense two-byte records initially. One role-only byte per triangle lacks material/provenance; per-vertex data costs more in these exports and needs a rule for vertices shared between roles. RLE/sparse-other storage can be a later measured optimization; no compressed-size promise. Extension is default-off/absent until P2 implements validated annotation; do not fabricate labels for existing exports. Preserve current OSM attribution and licensing; companion map-derived semantics inherit the data obligations, not a claim of a newly independent dataset. Its own index declares this and references the existing notice without changing that notice’s bytes.

A2’s optional consumer can translate triangle labels to a flat vertex attribute, duplicating **only its candidate GPU vertices** where an original vertex crosses role boundaries. Keep original package geometry untouched; measure the extra GPU memory/draw/triangle cost. Absent/off ignores sidecar and uses exactly the existing path. No global palette-slot mutation: select appearance by role/material/provenance for the relevant vertex/face. No native consumer is required to unblock an explicitly approved web-only trial.

## 3. Safety argument and required evidence

**Hash compatibility has a precise boundary.** Inserting `_ROLE` into a GLB changes its JSON/BIN and SHA-256; editing `world.json` changes its hash; adding files to an existing archive changes that archive’s hash. It is impossible to preserve those hashes merely because a consumer ignores the field. The separately addressed companion is recommended because it can leave **every legacy file and the complete legacy archive byte-identical**, while binding the new semantics to those unchanged hashes. If an integrated archive is later requested, its aggregate hash must change and that is a new contract decision, not an exception silently called compatible.

Native default safety: no shader, palette, `MeshBuffers` storage/equality, vertex/index order, seed consumption, feature choice, geometry budget, source-policy or renderer call path changes. P2 proposes a nil-by-default recorder parallel to emission; it must not influence control flow, palette insertion or mesh serialization. With recorder off, existing bytes must match. With recorder on, only the companion is written; annotation follows existing order without generating extra geometry. This is a design-level noninterference argument, **not an executed implementation proof**.

The **87 tests** cited by `docs/data/tunnel-guard.md` at 0d6a222 cover the map/tunnel/road-marking/map-layer selection, not a comprehensive surface-role suite. The **20 reproduced before/after road/static hashes** are independently described in `docs/review/a1-tunnel-fix-recheck-2026-10-08.md` at **ebe0e0b**; they do not prove full package or role correctness. After implementation, rerun that exact selected suite and its five-area harness, compare against the filed twenty witnesses with the same code/input/date/season controls, and separately compare all legacy package-file and archive bytes with extension off/on. A4 has not run these tests or exports in this design task and does not claim they pass a future implementation.

New fixtures (alongside, not replacing the existing 87):
- WorldGen semantic emission: **same hex for roof/wall/trim/door**, mapped-colour without material, valid/invalid material tag, explicit family inference versus none, roof gables/fascias/portico/window glass, garages/outbuildings, split-level/decomposed roofs and every authored LOD. Assert semantic roles independently of paint slots; no look values change.
- WorldMesh/annotation transforms: append, transform, partition, empty/non-building mesh and shared vertex across two roles; recorder absent/on must produce identical original mesh buffers and determinism witnesses. Do not add annotation to native `MeshBuffers` equality.
- `Tests/WorldPackageTests/WorldPackageTests.swift::packageIsDeterministicAndMatchesTheGenerator`, GLB round-trip and `AdaptiveTilePackerTests.swift`: external companion deterministic repeat, exact leaf/primitive triangle permutations, unchanged base files/world/archive; two-byte record/table/offset validation, unsupported version, truncated data, wrong hash/count, LOD/primitive mismatch; companion license classification/notice checks. Legacy package file-set assertions still run against the original package directory, not its sibling companion.
- A2 parser/default-off/candidate tests: no extra fetch or buffer when absent/off, equal-colour isolation, unsupported-role fallback, mapped precedence/provenance witnesses, safe rejection of stale sidecar, role-boundary vertex split and memory accounting; approved matched Sloan/Lakeview visual controls before any palette trial promotion. 5A later adds equivalent fixture vectors only if a native consumer is approved.
