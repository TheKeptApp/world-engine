Existing exported lot shade is content input, not a new fixed artistic number.

Added procedural noise amplitude **0**, added hue jitter **0**, added textures **0**. These zeros express excluded mechanisms, not invented look values. Preserve original topology, lot borders and mapped surface classification. Sample/shade policy must not vary with camera; no distance-fading base colour. Only already-authorized geometric detail LOD remains. This isolates lot identity, the first part of the broader variation gap.
