# Optional production surface companion reader

After the light trial: `main.js` → dynamic `surface-roles.js::loadSurfaceRoles` only when `?surfaceRoles=/same-origin-companion/index.json` is explicitly supplied. Absent/`off` has no module import, fetch or allocation. Rejection prevents scene-ready; records are published atomically at `world.surfaceRoles` only after every binding and provenance check. This is a reader, **not a palette application**: no GPU attributes, material colours, surface-role rows or generator edits.

Implements A4 `docs/execution/surface-role-implementation.md` Contract and A8 `docs/review/surface-role-companion-audit.md` production-rejection gap, using the corrected design bits (colour provenance 10–11, reserved 12–15). Validates fixed schema/tables/encoding; exact world, payload and every GLB hash; world-file byte counts; exhaustive unique mesh/primitive coverage; LOD/count/alignment/non-overlap/zero padding; GLB index accessor bounds; reserved record values; hash-bound scene feature tables; three-corner building identity; mapped tag and inferred colour-tuple witnesses. No material inference from colour/family; unsupported material provenance fails. Same-origin relative-path rules and redirect rejection apply. Repacked packages require regenerated companions and are rejected.

Per-record lookup is `world.surfaceRoles.word(glbPath, mesh, primitive, triangleOrdinal)`. IDs index bound records only, never select look rules. Prototype counts are source triangles, not placed-instance coverage. `other` stays unknown. Existing loader strips `_FEATURE`; the reader validates source bytes separately and does not attach labels to rewritten meshes. A future appearance consumer must preserve this binding and verify any GPU triangle permutation before using labels. No claim of GPU role consumption or a native port.

Tests include a self-contained same-colour roof/door fixture, default no-op, unsupported schema, corrupt package/payload/GLB bindings, wrong count/LOD/mesh, overlaps, duplicate/missing coverage, path traversal, reserved bits, missing provenance and actual A8 packages/repack. The optional large real-package tests use `SURFACE_ROLE_AUDIT_ROOT=/private/tmp/a8-surface-companion-results`; ordinary tests do not require those ignored artifacts. A first test mistakenly required a family field on sheds: corrected to the exporter's actual `generated.profile/role/colors/colorSet` inference witness, with no fabricated family value.

Used: surface-role-implementation.md Contract; surface-role-attribute.md §2; A8 audit. Mock: none (semantic reader). Deviation: GPU colour application remains deferred; validation does not label altered/repacked geometry.

Final production-reader validation PASS: 61 checks under heavy admission load 8.75. Actual Sloan: 271 primitives, 456,225 triangles, 912,608 payload bytes; Lakeview: 159 primitives, 1,797,471 triangles, 3,595,048 payload bytes. Roles/counts and exact package hashes match A8. Actual repack rejected at package hash. Same-origin fetch entry, no-fetch absent/off, wrong loaded manifest, mapped-tag/scene disagreement, mixed-corner and malformed records tested. Own lock released.
